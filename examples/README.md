# Exemplos de configuração

Todos os arquivos deste diretório são modelos inativos e terminam em
`.example`. Os valores usam domínios reservados, UUID nulo e marcadores que
devem ser recusados até o provisionamento administrativo.

O build materializa os nomes operacionais dentro do bundle, com os modos
previstos no manifesto. Não renomeie estes arquivos diretamente sobre `/etc` e
não armazene credenciais, chaves ou valores de hosts reais no repositório.

Consulte [`../docs/05-INSTALLATION.md`](../docs/05-INSTALLATION.md) antes de
preparar uma instalação.
